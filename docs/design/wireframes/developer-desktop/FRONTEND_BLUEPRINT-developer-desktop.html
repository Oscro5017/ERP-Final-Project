เส้นทางหลักสำหรับพัฒนา

ก่อนเดโม: nav/redirect → Farm + Activities → Weather/history → Overview ลด mock → Customer panel ปลอดภัย → Developer status shell.

รอ Phase 2: ตัดสิน product + StockMovement + InputCatalog ก่อน → ระดับ A รับเข้า/ส่งออก/input/ปรับยอด → ระดับ B เมล็ด → ระดับ C ใบผสม → Finance/D5/Contract/Order.

ยืนยันตัวเลขด้วย backend aggregation; UI แสดง unavailable เมื่อ API ยังไม่มี. ไม่แก้โค้ดจากไฟล์ wireframe นี้.
