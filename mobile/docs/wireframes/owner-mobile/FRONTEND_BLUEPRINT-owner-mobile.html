1. แผนผังเมนู (Sitemap) As-Is vs To-Be

เมนูเดิม (As-Is) โครงใหม่ To-Be (Mobile Bottom Nav & Drawer) สถานะ API

Crop Cycles / Harvest / Activities ฟาร์ม (Farm) - ช่องที่ 2 ในแถบล่าง มี API จริง
Sales / Inbound / Outbound รับเข้า / ส่งออก (Transactions) - ช่องที่ 3 ในแถบล่าง ต้องสร้าง backend (Phase 2)
Inventory / Tables / Batches สินค้า & คลัง (Inventory) - ช่องที่ 4 ในแถบล่าง มี API จริง
Costs / Reports การเงิน (Finance) - ช่องที่ 5 ในแถบล่าง ต้องสร้าง backend (Phase 2)
Weather / Customers / Settings เมนูแถบบน / Drawer (สภาพอากาศ, คู่ค้า, ตั้งค่า) มี API จริง
